Supported Bank Formats Guide

A visual guide explaining how our engine reads and maps different bank statement formats.

Bank of Baroda (BOB) Native Parser

  • Dual Post-Posting Columns The parser automatically tracks and maps GL. Date and Value Date. Postings use the GL Date for ledger precision.
  • Dedicated Instrument Column If Cheque/DD/Ref numbers are listed under Instrmnt Number, they are parsed and imported directly into Tally.
  • Clean Debit / Credit Split Transaction values are extracted from separate Debit Amount and Credit Amount columns, accurately maintaining Cr/Dr indicators in Tally.
  • Verification Codes Columns containing user IDs (e.g., Entry User Id) are ignored automatically during text cleanup.

Hybrid Column Mapper Interactive UI

Hybrid Mapping Engine: Standard table layout statement PDFs (like State Bank of India, Axis Bank, and Union Bank of India) can be converted instantly by mapping their header columns in our interactive Hybrid Parser.
  • Date Columns mapping Map the Txn Date (Column 1) as the primary transaction date for ledger entry.
  • Detailed Description Map the Description column (Column 3) to capture full transfer descriptors (e.g., BY TRANSFER-UPI/CR/...).
  • Ref No. / Cheque Number Map the Ref No./Cheque No. column (Column 4) to capture the reference numbers for auditing.
  • Debit & Credit Split Simply assign Debit (Column 6) and Credit (Column 7) to extract negative and positive flows.
  • Tran Date Mapping Assign Tran Date (Column 1) to record the transaction date.
  • Transaction Particulars Map the Transaction Particulars column (Column 3) to fetch descriptions (e.g., Paytm Pay/Payment).
  • Unified Amount Column with DR/CR Indicator Map the Amount(INR) (Column 5) and pair it with the DR/CR (Column 6) indicator column. The engine automatically signs the transaction values.
  • Chq No & Branch Name Easily map reference and branch details if they are required in Tally narration fields.
  • Serial Number Column The serial identifier Sl is automatically ignored, focusing strictly on transaction data.
  • Standard Date Field Map the Date column (Column 2) to set voucher dates in Tally.
  • Clean Particulars Map Particulars (Column 3) to read and parse payee and transaction info (like Zomato payments).
  • Withdrawal & Deposit Mapping Assign Withdrawal (Column 5) as Debit and Deposit (Column 6) as Credit to capture transaction values.
