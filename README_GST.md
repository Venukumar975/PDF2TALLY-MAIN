# GST Offline Conversion Utilities: GSTR-1 & HSN

This document details the expected input Excel/CSV structures and the respective output JSON schemas generated by the Flask backend for GSTR-1 and HSN Offline file preparation.

> [!NOTE]
> **Column Order**: The physical order of columns in your Excel sheet **does not matter** for either tool (e.g., you can have the date column before the GSTIN column). The parser looks up columns strictly by their header name, not by column position (A, B, C, etc.).

---

## 1. GSTR-1 Offline Ingestion

*   **Excel Sheet Name**: `b2b` (case-insensitive)
*   **Header Starts At**: Row 4 (index `header=3` in Pandas)

### Input Excel Structure
The parser expects these **exact** column headers (order does not matter):

| Header Column Name | Description | Example Value |
| :--- | :--- | :--- |
| `GSTIN/UIN of Recipient` | Customer's GSTIN | `99ABCDE1234R1Z1` |
| `Invoice Number` | Unique Tax Invoice ID | `INV-9999-999` |
| `Invoice date` | Invoice Date | `01-04-2025` (formats: `dd-mm-yyyy`, `dd/mm/yyyy`) |
| `Invoice Value` | Total invoice value (GST inclusive) | `1180.00` |
| `Place Of Supply` | Place of Supply state code prefix | `99-Mock State` or `99` |
| `Taxable Value` | Invoice value excluding tax | `1000.00` |
| `Rate` | GST slab rate applied | `18` or `18%` |

## 2. HSN Offline Ingestion

*   **Excel Sheet Name**: `hsn` (case-insensitive)
*   **Header Starts At**: Row 4 (index `header=3` in Pandas)
*   **Dynamic Dividers**: The parser switches target grids when it encounters a row whose HSN column contains the text `B2B Supplies` or `B2C Supplies`.

### Input Excel Structure
The parser is flexible and maps column header variations automatically (order does not matter):

| Normalized Field | Accepted Headers | Example Value |
| :--- | :--- | :--- |
| **HSN** | `hsn`, `hsn code`, `hsn/sac` | `99999999` |
| **Description** | `description`, `desc` | `MOCK PRODUCT CATEGORY A` |
| **UQC** | `uqc`, `unit`, `uom` | `NOS` (Defaults to `OTH` or `NA` if empty) |
| **Total Quantity** | `total quantity`, `quantity`, `qty` | `10` |
| **Total Value** | `total value`, `value`, `total amt` | `1180.00` |
| **Taxable Value** | `taxable value`, `taxable amount`, `taxable val` | `1000.00` |
| **Integrated Tax** | `integrated tax amount`, `igst`, `igst amount` | `0` |
| **Central Tax** | `central tax amount`, `cgst`, `cgst amount` | `90.00` |
| **State/UT Tax** | `state/ut tax amount`, `sgst`, `sgst amount` | `90.00` |
| **Cess** | `cess`, `cess amount` | `0` |
| **Rate** | `rate`, `tax rate` | `18` or `18%` |
