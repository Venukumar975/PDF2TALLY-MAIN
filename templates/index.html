Supported Formats Guide

Learn which bank statement formats and Excel layouts are supported by the converter engine.

Text-Copyable PDFs ONLY (No Scanned Documents): Only upload digital PDFs where you can select and copy the text. Scanned images, mobile phone photos, or photocopy PDFs are NOT supported because this app runs offline and does not use visual character guessing (OCR).

Bank of Baroda (BOB) Statements Native Parser

This format matches for Native Conversion (zero config needed, app parses automatically).

  • Natively Parsed and Converted These statements are converted directly without manual column configuration.
  • Dual Posting Dates Supported The engine automatically identifies GL Date and Value Date, setting vouchers to posting dates.
  • Dedicated Instrument Extraction Cheque, DD, or Ref numbers listed under Instrument Number columns are parsed cleanly to Tally references.
  • Clean Debit/Credit Separation Withdrawal and deposit amounts are parsed from separate Debit and Credit columns instantly.

Generic Table Statements User Guided Conversion

For these layout formats, the user must guide the app using the mapping wizard (linking columns for Date, Narration, and Amounts) so the app can properly extract the valid transactional rows.

  • Convertible via Guided Mapping Map header columns to convert this layout successfully into standardized Tally XML.
  • Date Columns Mapping Assign the Txn Date column to cleanly record posting dates in Tally.
  • Description Narration Extraction Description fields are automatically extracted to construct neat narration entries.
  • Ref/Cheque Reference Tracking Map Ref No./Cheque No. to record auditing reference identifiers.
  • Convertible via Guided Mapping Align Axis statement columns inside the mapping setup to complete the conversion.
  • Unified Amount and Indicator Map unified amount columns with a DR/CR indicator to resolve negative and positive transactions.
  • Particulars Descriptors Captures transaction particulars like Paytm/UPI payees to use for ledger names.
  • Chq No and Branch Support Allows mapping of cheque numbers and branch names to enrich narration text.
  • Convertible via Guided Mapping Simply match headers to parse this structured table format instantly.
  • Withdrawal & Deposit Mapping Assign columns for Withdrawal (Debit) and Deposit (Credit) values.
  • Clean Date Mapping Maps transaction dates directly from the Date column to Tally vouchers.
  • Payee Narration Identification Converts payee descriptions from the Particulars column into transaction narrations.

Excel Preparation & Upload Rules

1. Sheet Naming & Placement

  • For GSTR-1 invoices, name the Excel tab sheet b2b (case-insensitive).
  • For HSN summaries, name the Excel tab sheet hsn (case-insensitive).
  • Columns can be in any order (the app matches purely by the header name).

2. Header Rows & Missing Columns

  • Header Row: Place your column names on Row 4 of the sheet. If they start elsewhere, change the "Header Row" field in the form.
  • Empty/Optional Columns: Columns like Reverse Charge, Cess, IGST, CGST, or SGST can be left empty or omitted. The app will calculate them automatically!
