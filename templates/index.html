Supported Formats Guide

Learn which bank statement formats and Excel layouts are supported by the converter engine.

⚠️ Text-Copyable PDFs ONLY (No Scanned Documents): Only upload digital PDFs where you can select and copy the text. Scanned images, mobile phone photos, or photocopy PDFs are NOT supported because this app runs offline and does not use visual character guessing (OCR).

🏦 Bank of Baroda (BOB) Statements

The app supports standard BOB digital e-statements. The system reads them using these rules:

  • Date Format: Must be in the format DD-MM-YYYY (e.g. 02-04-2025).
  • Columns: The statement must have columns for: Transaction Date, Value Date, Description/Narration, Amount (Withdrawal/Deposit), and Running Balance.
  • Running Balance: Running balance must end with a clean Cr or Dr marker.
  • Opening Balance: The parser searches for the exact phrase "Opening Balance" to extract the starting balance.

🏦 State Bank of India (SBI) Statements

The system automatically supports 4 different formats of digital SBI statements:

1. Corporate Tabular Format (Branch Code)

Used for corporate accounts. It contains columns: [Txn Date] [Value Date] [Description] [Ref No/Cheque No] [Branch Code] [Debit] [Credit] [Balance].

Dates: DD/MM/YYYY (e.g. 15/05/2025).

2. Standard Numeric Slash Format

Standard personal account e-statement format with columns separated by slashes in the dates.

Dates: DD/MM/YYYY (e.g. 11/01/2026).

3. Textual Month Tabular Format

Standard retail e-statement format containing day, textual abbreviated month, and year.

Dates: D MMM YYYY (e.g. 4 Jun 2025 or 10 May 2025).

4. Legacy Wrapped Line Format

Older e-statement formats where dates and descriptions wrap across multiple lines of text.

Dates: D MMM YYYY (e.g. 9 May 2025).

🌾 Ashramam Cash Receipts Excel

The spreadsheet must contain clean columns for your receipts batch. The converter expects the following details:

  • File Types: Excel Workbooks (.xlsx, .xls) or comma-separated tables (.csv).
  • Expected Columns: Receipt Date, Name of Donor, Amount, and Receipt Number.
  • Automatic Translation: Names written in Telugu script (like రామారావు) are translated automatically to English script (like Ramarao) using our integrated dictionary.
