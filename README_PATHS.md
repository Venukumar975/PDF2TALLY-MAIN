# PDF2TALLY Directory & File Path Reference

This document serves as a complete technical guide detailing where all persistent application data, configuration files, caches, logs, and installation binaries are stored on a user's Windows system.

---

## 📁 1. Persistent Application Data (`LOCALAPPDATA`)

All dynamic files generated by the application during runtime (license info, user configurations, localized mappings, Tally synchronized ledger caches, and transaction logs) are stored strictly inside the user's local application data folder:

`C:\Users\<Username>\AppData\Local\PDF2TALLY\`

### Detailed Path Reference Table

| Category | File / Folder Path | Description |
| :--- | :--- | :--- |
| **🔑 License File** | `C:\Users\<Username>\AppData\Local\PDF2TALLY\.lic` | Stores the encrypted offline license activation keys and hardware signature verification status. |
| **📋 Saved Layouts** | `C:\Users\<Username>\AppData\Local\PDF2TALLY\saved_layouts.json` | Stores user-configured hybrid bank statement layouts (custom columns and header mappings). |
| **🔤 Telugu Mappings** | `C:\Users\<Username>\AppData\Local\PDF2TALLY\telugu_mappings.json` | Contains the dictionary mappings used by Aksharamukha for transliterating Telugu cash voucher descriptors. |
| **🏦 Tally Ledgers** | `C:\Users\<Username>\AppData\Local\PDF2TALLY\tally_companies\` | Subdirectory containing cached ledger lists synchronized from local Tally companies. |
| **📄 Temp Uploads** | `C:\Users\<Username>\AppData\Local\PDF2TALLY\temp_uploads\` | Directory holding temporary session copies of uploaded bank statement PDF files. |
| **🪵 Application Logs** | `C:\Users\<Username>\AppData\Local\PDF2TALLY\logs\app.log` | Standard runtime log file detailing diagnostics, motherboard/BIOS signatures, and API routing. |
| **🪵 Full Text Logs** | `C:\Users\<Username>\AppData\Local\PDF2TALLY\logs\fulltext.log` | Dumps the raw text extracted from processed statements (cleared and recreated on each PDF scan). |

## ⚙️ 2. Program Installation Directory

When the setup installer is run, all compiled binaries, support DLLs, and obfuscated PyArmor runtimes are installed into the standard Windows Program Files directory:

`C:\Program Files (x86)\PDF2TALLY\`

### Key Files in Installation Folder

*   **`PDF2TALLY.exe`**: The main executable container. Starts the local Flask server on a dynamic free port and opens the WebView2 viewport window.
*   **`unins000.exe` / `unins000.dat`**: The uninstaller executable and database registry entries used to cleanly remove the application.
*   **`_internal/`**: Contains the bundled Python standard libraries, dependencies (pandas, openpyxl, pymupdf, pywebview), and template assets.
